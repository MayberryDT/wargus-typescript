The cache is a module-local `WeakMap<WorldState, Cache>`. It rebuilds on tick,
`world.units` reference, array length, or explicit invalidation-generation
change. Map construction inserts only the first occurrence of each ID, so
production lookup preserves authoritative `.find` behavior. Duplicate IDs are
recorded and `assertWorldUnitIndexIntegrity` surfaces them as a development
contract failure without changing the returned first entry.

The focused verifier covers stable reuse, tick change, push/length change,
filter/reference change, temporary same-length replacement and restoration,
same-reference/same-length explicit invalidation, independent worlds,
load-created identity, retained dead units, first-match duplicates, reset,
serialization exclusion, the real command wrapper, and the exact 22-statement
runtime mutation inventory. Its captured diagnostics are:

| Fixture | lookups | rebuilds | invalidations | duplicate IDs |
|---|---:|---:|---:|---:|
| lifecycle | 14 | 11 | 1 | 0 |
| duplicate | 1 | 1 | 0 | 1 |
| after reset | 0 | 0 | 0 | 0 |
| command path | 2 | 1 | 0 | 0 |

The final inventory remains 11 assignments, 11 pushes, and zero
same-reference/same-length runtime mutations. Therefore no current
`orders.ts` mutation site requires an explicit invalidation call. The public
invalidation API and its behavioral test are present for any future mutation

`world.units` remains authoritative and ordered. The index and diagnostics
are not fields on `WorldState`, renderer input, canonical deterministic
