## Attempted bounded protocol

Each row waited for a fully loaded page with `loadingVisible === false`, then
used:

1. 5 seconds of warmup;
2. reset/start at capture offset 0;
3. heap snapshot at +10 seconds;
4. CPU/input snapshot at +15 seconds;
5. stop/final heap snapshot at +20 seconds;
6. a hard guard that terminated and cleaned the tab before 30 seconds.

For `command-18`, the intended protocol also requires both the strict smoke
action and real keyboard/mouse input with nonzero input-to-command and
input-to-next-render samples. The incomplete matrix never reached that row.

## Frozen budgets

- `army-100`: frame p95 ≤33.3 ms, p99 ≤50 ms, and
  `over50Ms/sampleCount` ≤1%.
- `command-18`: input-to-command p95 ≤50 ms and
  input-to-next-render-callback p95 ≤100 ms, with nonzero synthetic and real
  input samples.
- Every profile: scheduler dropped delta = 0 and maximum backlog ≤0.25 s.
- Heap: used heap growth across equal 10-second windows ≤15% when supported.

**No budget verdict is recorded.** The matrix is incomplete, and the available
fallback used SwiftShader under unrelated CPU contention. Passing or failing
values from these partial artifacts would not establish an honest baseline.
