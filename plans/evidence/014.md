## Review-fix implementation

### Construction manager

Every scripted and direct Hall/supply/Barracks/lumber/blacksmith/tech/shipyard
construction request now uses one shared path. It counts completed buildings,
foundations, and unpaid `build` orders in `phase: "to-site"`; reserves every
valid unpaid order's cost before accepting another; and deterministically
retasks source-eligible workers travelling to a resource without stealing
build, oil-platform, repair, or active-gather work. Resources are still deducted
only when the builder reaches the site.

`verify:plan014-ai-runtime` runs the production manager against real fixed-demo
world state for the one-Hall opening, a second Barracks with only a travelling
worker available, and competing unpaid costs. It advances the real build order
to a foundation and checks exact arrival deduction, no duplicate request, and
no cancellation caused by overcommit.

### Scripted forces and saves

Force targets now use exact race-resolved unit types, and assignment claims an
id once across target rows. A force detaches only after every member receives a
real attack or attack-move order; when no reachable pressure point exists, its
slot and ids remain retryable. The focused verifier covers a mixed
cavalry-mage/mage composition and the no-pressure retry path.

Save normalization replays the selected source script to bound script index,
force slots, targets, roles, assigned ids, launches, and per-launch ids. It
filters missing or wrong-type active ids, deduplicates them deterministically,
caps launch history to the script, and prevents active/launch overlap. The
runtime verifier mutates a save with oversized/stale force state and loads it
through the real save loader before checking those bounds.

### Honest browser gate and live evidence

Playwright `1.61.1` is pinned in `package.json` and the lockfile. Production
smoke launches Vite `preview`; development smoke launches the development
server. Chromium resolves from Playwright unless `CHROME_BIN` is explicitly
provided, so the command no longer embeds Halla paths or an undeclared external
module. A focused basics shard retains audio/music, fog, selection,
right-click, and screenshot-transition checks within the browser time budget.

The smoke surface now publishes bounded live AI evidence from the running
world: exact force targets and assigned/ordered units, detached launches,
desired/completed/foundation/in-flight build counts, pending unpaid orders and
reserved resources, difficulty factors, AI-owned exploration/scout state,
production queues with total/remaining train seconds, and foundations with
total/remaining build seconds. Plan 014 browser mode validates this live shape;
the synthetic script and knowledge fixtures remain focused unit/integration
checks only.

For a separately authorized browser run,
`WARGUS_BROWSER_RUNTIME_REPORT=/absolute/path.json` writes the accepted final
payload after assertions. The versioned JSON includes the exact M01/M04/M07
fixture result when selected, live tick/pause/speed and AI evidence, and the
update/render sample. This is the reproducible artifact hook for reconciling
M07 and preserving real M09 duration/progressed-performance evidence; it does
not replace the visible Task 9 session.
